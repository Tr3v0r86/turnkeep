# Hardware provenance

The case design and generators were authored for the project. This public package extracts the current geometry from the original `trevos-enclosure-repair-v0.3` and retained `trevos-character-case-v0.2` designs. `case.py` contains only the retained body/lid portion of `reference/source_v02.py`; `build.py` is the v0.3 generator adapted to import it normally and make manufacturer-board checks optional. No miniature model, personal character sheet, derived miniature image, historical repair, backup or entire archive folder is included.

`package.py` retains the original eight-piece layout and hardware-map drawing with portable fonts. `upholstery/make_patterns.py` retains the current two-connected-net geometry; the product title changes to Turnkeep. `render.py` is a new portable render of the generated original-part STL meshes, not an illustrative replacement design. The current faceplate stays bare/painted. No model of the electronic board appears in the public render.

The external manufacturer reference is [LILYGO T-Display-S3 board STEP](https://github.com/Xinyuan-LilyGO/T-Display-S3/blob/main/dimensions/t-display-s3-full.stp), SHA256 `d33dc105aa1e25a1408f3effda5a59319ef69044984d57ccb6d482bb78a589a5`. Its redistribution license has not been established, so the reference, its derived meshes, and assemblies embedding it are excluded. The optional `--board-step` argument uses a separately acquired file only for checks; exported STEP always contains original printed parts only. Dimensional interfaces in the original design were fitted against that reference; current physical hardware remains the acceptance authority.

`validation.json` is produced by the default source build and states whether board checks ran. `validation-with-board.json`, when present, is a result-only record from the separately acquired nominal model. It contains measurements/check outcomes and no model geometry. Dependency licenses remain their respective authors'; Python packages are installed rather than vendored.
