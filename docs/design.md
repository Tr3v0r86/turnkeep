# Turnkeep website design

## Identity

Turnkeep keeps the pieces and state of a tabletop turn together. The descriptor is **An open-source character case**; the lead is **A character case, open by design**. This is a maker project, with honest evidence and direct access to its files. The case geometry is the central visual, not invented fantasy ornament. The name is a working project name, not a claim of trademark clearance.

## Visual system

| Token | Hex | Role |
| --- | --- | --- |
| Felt | #183B46 | Main background |
| Deep seam | #102A33 | Footer and recesses |
| Ivory | #F0F1E8 | Light surfaces and text |
| Brass | #E2B96F | Primary action |
| Ink | #17323B | Text on light surfaces |
| Muted | #B7CDD0 | Secondary text on dark |

Bricolage Grotesque carries the wordmark, headings and body; IBM Plex Mono carries dimensions and technical labels. Fonts are locally hosted with OFL notices. Body text is 18 px with 1.55 line height. The asymmetric desktop opening becomes a single column on narrow screens. The L-shaped tray and compartment geometry should remain recognizable in all replacement hero imagery. Label CAD renders as renders; do not present them as physical build evidence.

## Reader path

The case → how it works → build guidance → files → development journal. A single static document keeps navigation and downloads available without JavaScript. Technical detail lives beside its editable source in the repository. Full-project download includes the original sources and exports; per-file SHA-256 checksums expose exactly what is inside.

## Accessibility and maintenance

Use semantic sections, a first-focus skip link, visible keyboard focus, native disclosures and visible navigation. Keep illustrations paired with text descriptions. Preserve 320 px reflow and readable tables. Respect reduced-motion preference. Do not add autoplay or scroll hijacking. Update evidence labels when a physical check actually passes, and version the file set when geometry or firmware changes.

The product thesis now leads: **Bring the game back to the table.** Phone preparation supports offline play instead of competing with it. The setup demo is an interactive, explicitly simulated flow; the real current device and future display concepts remain visibly distinct. The maker invitation is **Make it. Modify it. Copy it. Reinvent it. Make it yours.** Keep optional coffee support separate from the upcoming assembled-box offer.
